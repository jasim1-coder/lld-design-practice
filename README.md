# Low Level Design (LLD) Practice – System Design Fundamentals

A curated collection of **Low Level Design (LLD) problems** implemented in **C# (.NET)**, focused on **clean architecture, SOLID principles, and real-world interview scenarios**.

This repository is created as part of my continuous learning to improve **object-oriented design**, **backend system modeling**, and **LLD interview readiness** for **MNC-level software engineering roles**.

Each design focuses on **clarity, extensibility, and interview-level depth rather than over-engineering**.

---

## 🎯 Purpose of This Repository

- Practice Low Level Design in a structured and repeatable manner  
- Convert requirements into clean class designs and interactions  
- Apply SOLID principles and common design patterns  
- Build an interview-ready GitHub portfolio  

Each folder in this repository represents **one independent LLD problem**, designed and implemented from scratch.

---

## 📁 Repository Structure

Each folder represents a **self-contained Low Level Design problem** with its own:
- Problem statement  
- Assumptions  
- Source code  
- Tests (where applicable)
